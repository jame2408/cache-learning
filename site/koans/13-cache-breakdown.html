Koan 13

快取擊穿

堡壘的城牆有一萬塊磚。只要一塊破裂，洪水就會湧入。

理解

快取擊穿（Cache Breakdown）是指一個極度熱門的 key 過期的瞬間，大量併發請求同時湧向資料庫查詢這個 key，造成資料庫瞬間承受巨大壓力。

與驚群效應（Stampede）的差別在於：驚群是多個 key 同時過期；擊穿是單一個「超級熱門」的 key 過期。一個 key 就足以壓垮系統。

模擬

觀察熱門 key 的 TTL 倒數。當它過期的瞬間，所有流量集中湧入。

思考
快取擊穿與驚群效應的主要區別是什麼？
擊穿是關於單一個熱門 key
擊穿是關於很多 key
它們完全一樣
洞察
防止擊穿的策略：永不過期 + 背景刷新（讓 key 永遠有效，由背景程序定期更新）、Mutex 鎖（與驚群相同的鎖機制）、以及預計算熱門 key（提前識別並特殊處理已知的熱門 key）。核心思想是：對於重要的 key，不要讓它有「空窗期」。
