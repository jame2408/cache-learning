快取分區（分片）

一個快取放不下所有。把它分成碎片——但每片必須知道自己的責任。

概念

當快取資料量超過單一節點的容量時，需要將資料分散到多個節點。這就是分區 (Partitioning) 或分片 (Sharding)。

簡單的 modulo 雜湊 (key % N) 在節點數量變化時會導致大量 key 重新映射。一致性雜湊 (Consistent Hashing) 將節點和 key 都映射到環上，節點變化時只影響相鄰區間的 key。

互動模擬

觀察一致性雜湊環。新增或移除節點，看哪些 key 需要重新映射。與 modulo 雜湊比較。

思考
為什麼一致性雜湊比 modulo 雜湊更受青睞？
節點變化時，key 的重新分配量最少
速度更快
實作更簡單
洞察
虛擬節點 (vnodes) 能改善雜湊環上的負載分布。每個實體節點在環上放置多個虛擬點，讓 key 的分布更均勻。

DynamoDB、Cassandra 和大多數分散式快取都使用這項技術。Redis Cluster 使用 16384 個雜湊槽 (hash slots)，也是類似的概念。

當你看到 key 分布不均，考慮增加虛擬節點的數量。
